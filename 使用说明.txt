GameSaveCloudQt 使用说明
版本：0.2.0
作者：baolibaobao


一、软件用途

GameSaveCloudQt 是一个 Windows 游戏存档管理工具，用于扫描本机 Steam 游戏、识别游戏存档目录、创建本地存档快照，并通过夸克网盘/OpenList 网关上传或下载快照。


二、首次运行

1. 双击 GameSaveCloudQt.exe 启动软件。
2. 软件会自动扫描 Steam 安装目录和 Steam 游戏库。
3. 首次扫描可能需要等待一会儿，中文游戏名和存档路径会在后台补齐。
4. 如果部分游戏没有识别出存档目录，可以进入游戏详情页手动指定存档目录。


三、设置本地快照目录

1. 在游戏库顶部点击“设置存档目录”。
2. 选择一个用于保存本地快照的文件夹。
3. 软件会在该目录下创建 snapshots 和 logs 等子目录。

建议选择空间充足、路径稳定的磁盘目录，不建议选择系统临时目录。


四、连接夸克网盘

1. 打开“云同步设置”。
2. 粘贴夸克 Cookie。
3. 点击连接或测试。
4. 连接成功后，软件会启动本地 OpenList 网关，并通过 WebDAV 访问夸克网盘。

OpenList 数据目录固定在：
%APPDATA%\GameSaveCloudQt\openlist

这个目录用于保存 OpenList 配置、夸克挂载状态和日志。不要手动删除 data.db，否则需要重新连接夸克 Cookie。


五、创建本地快照

1. 在游戏库中点击游戏卡片进入详情页。
2. 确认“存档可同步”。
3. 点击“创建快照”。
4. 创建完成后，本地快照列表会显示 zip 快照文件。

如果存档目录为空，软件会提示当前没有可用存档文件。


六、上传快照

1. 先确认夸克网盘连接成功。
2. 进入游戏详情页。
3. 可以选择上传最新快照、上传全部快照或上传指定快照。
4. 上传时页面会显示文字进度和进度条。
5. 上传过程中请不要重复点击上传按钮。

云端默认目录：
/Quark/GameSaveCloudQt


七、下载快照

1. 先确认夸克网盘连接成功。
2. 进入游戏详情页。
3. 刷新云端快照列表。
4. 可以选择下载最新快照、下载全部快照或下载指定快照。
5. 下载时页面会显示文字进度和进度条。

下载后的快照会保存到该游戏的本地快照目录中。


八、恢复快照

1. 进入游戏详情页。
2. 在本地快照或云端快照列表中选择要恢复的快照。
3. 点击恢复。
4. 软件会在覆盖前创建恢复备份，方便回退。

恢复前建议关闭对应游戏，避免游戏进程占用存档文件。


九、自动同步

1. 可以在自动同步页面开启全局自动同步。
2. 可以为单个游戏开启或关闭自动同步。
3. 软件会监控游戏进程。
4. 当游戏关闭后，会检查存档变化并按设置执行同步。

如果没有识别到游戏主程序，自动同步可能无法触发，需要手动上传快照。


十、配置云同步

软件会把部分游戏配置同步到云端：
/Quark/GameSaveCloudQt/config/config-sync.json

会同步的内容包括：
- 游戏名称和基础元数据
- PCGamingWiki 匹配信息
- 存档路径候选信息
- 云端快照索引相关信息

不会同步的内容包括：
- 夸克 Cookie
- OpenList data.db
- WebDAV 密码
- 启动项设置
- 自动同步开关
- 手动游戏 exe 路径

换设备后，来自配置云同步的存档路径只作为候选，需要重新确认后再同步。


十一、数据文件位置

软件配置和缓存：
%APPDATA%\GameSaveCloudQt

OpenList 数据：
%APPDATA%\GameSaveCloudQt\openlist

OpenList 日志：
%APPDATA%\GameSaveCloudQt\openlist\log

游戏数据缓存：
%APPDATA%\GameSaveCloudQt\game-data-cache

本地快照目录：
由用户在软件中设置。


十二、哪些文件可以清理

通常可以清理：
- 旧的本地快照 zip
- 旧的恢复备份
- 旧日志文件
- game-data-cache 中不再需要的游戏缓存

不要随便删除：
- %APPDATA%\GameSaveCloudQt\openlist\data.db
- %APPDATA%\GameSaveCloudQt\openlist\config.json
- 正在使用中的本地快照目录

删除 OpenList 数据库后，夸克挂载配置会丢失，需要重新连接 Cookie。


十三、常见问题

1. 打开软件后游戏名还是英文

首次运行会先显示 Steam 本地清单中的名称，然后后台请求 Steam 中文资料。等待一会儿即可。如果一直没有更新，可以点击“重新扫描”。

2. 一直显示正在扫描存档

可能是存档路径还在后台识别，或该游戏在 PCGamingWiki 中没有可用路径。可以点击游戏详情页查看状态，必要时手动指定存档目录。

3. 夸克 Cookie 健康检查失败，但上传下载正常

以实际上传、下载、目录读取结果为准。健康检查分为 OpenList 启动、挂载状态、WebDAV 读取、探针写入等步骤，单个探针失败不一定代表 Cookie 已过期。

4. 提示同名文件或正在下载

夸克/OpenList 有时会对同名文件覆盖产生延迟。稍等后重试，或刷新云端列表。

5. 上传或下载没有反应

先确认云同步设置里夸克网盘连接成功，再查看日志页面。上传和下载过程中按钮会暂时不可重复点击。

6.如何获取夸克网盘cookie

教程链接：https://www.dc6i.cn/150.html


十四、卸载说明

通过 Windows 设置或安装程序自带卸载项卸载软件，只会删除安装目录中的程序文件。

如果需要彻底清理用户数据，可以手动删除：
%APPDATA%\GameSaveCloudQt

删除前请确认里面没有仍需保留的配置、日志或 OpenList 数据。
